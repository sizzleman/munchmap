# Project rules (Antigravity)

This repo keeps all agent instructions in one place so every AI tool behaves the same way:

1. Read and follow `/AGENTS.md`: project rules, architecture, conventions.
2. Read `/LESSONS.md` before starting. Append a lesson when something non-obvious happens (format is in that file).
3. Repeatable workflows are in `/.claude/skills/*/SKILL.md`. Treat them as step-by-step playbooks even though they're stored in a Claude folder.

Do not duplicate rules here. Edit `AGENTS.md` instead.
